Quick start

Costruisci il primo roster locale.

Un percorso operativo breve per testare Roster Burrito Local da progetto vuoto a calendario esportato.

01

Installa e apri

Scarica l'installer Windows da GitHub Releases, apri l'app e mantieni i file progetto su un disco locale che controlli.

02

Crea un progetto

Parti dalla workspace autosalvata oppure usa Salva con nome per creare un file `.shiftlocal` dedicato al roster.

03

Aggiungi le basi

Inserisci clinici, tipi turno, template copertura, impostazioni, festivita e limiti locali.

04

Inserisci input mensili

Registra preferenze manuali, date indisponibili, ferie e note di scambio direttamente nella workspace locale.

05

Genera e controlla

Esegui il planner, rivedi slot aperti e riepiloghi equita, poi modifica input o assegnazioni.

06

Esporta e tieni tutto locale

Salva il progetto ed esporta il calendario quando e pronto. I dati restano locali salvo tua condivisione.

Troubleshooting

I problemi locali dovrebbero essere facili da isolare.

L'app desktop scrive log locali e usa una API locale solo su loopback. Se il solver non parte, controlla prima Java, poi il percorso del log mostrato dall'app.

Avviso installer

Le build non firmate possono generare prompt di sicurezza Windows finche arriva la firma.
