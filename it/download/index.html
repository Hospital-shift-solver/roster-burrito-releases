Prima di installare

  • Scarica solo dal repository ufficiale GitHub Releases.
  • Confronta lo SHA-256 dell'installer con il checksum nelle note release.
  • Windows puo mostrare un avviso publisher sconosciuto finche le build non sono firmate.

Requisiti

  • Windows x64.
  • Accesso al disco locale per file `.shiftlocal` ed export.
  • Nessun account cloud, setup Supabase o database hosted richiesto.

Installa e usa

Dal download all'export del roster.

01

Scarica

Prendi l'installer Windows piu recente dal repository pubblico GitHub Releases.

02

Crea o apri

Avvia una workspace locale o apri uno dei progetti demo `.shiftlocal`.

03

Pianifica in locale

Aggiungi clinici, regole, ferie e preferenze, poi esegui il solver locale.

04

Esporta

Rivedi equita, modifica il roster ed esporta quando il calendario e pronto.
