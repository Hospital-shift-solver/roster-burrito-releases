Before you install

  • Download only from the official GitHub Releases repository.
  • Compare the installer SHA-256 with the checksum in the release notes.
  • Windows may show an unknown-publisher warning while builds are unsigned.

System requirements

  • Windows x64.
  • Local disk access for `.shiftlocal` project files and exports.
  • No cloud account, Supabase setup, or hosted database is required.
