Quick start

Build your first local roster.

A short operating path for testing Roster Burrito Local from an empty project to an exported schedule.

01

Install and open

Download the Windows installer from GitHub Releases, open the app, and keep project files on a local drive you control.

02

Create a project

Start with the autosave workspace or use Save As to create a named `.shiftlocal` project file for the roster you are building.

03

Add the roster basics

Add clinicians, shift types, coverage templates, planning settings, holidays, and any local eligibility limits.

04

Enter monthly inputs

Capture manual preferences, unavailable dates, PTO / leave, and swap notes directly in the local workspace.

05

Generate and review

Run the planner, review open slots and fairness summaries, then adjust inputs or manual assignments before generating again.

06

Export and keep files local

Save the project and export the schedule when ready. Project data stays local unless you share the file yourself.

Troubleshooting

Most local issues are easy to isolate.

The desktop app writes local logs and uses a loopback-only local API boundary. If the solver cannot start, check Java availability first, then open the desktop log path shown by the app.

Installer warning

Unsigned early builds can trigger Windows security prompts until signing is added.
